# Esse reposiório descreve 3 ténicas dentro de POO

# Herança

- As classes filhas SEMPRE herdarão os métodos da classe pai, isso gera uma inflexibilidade no código, já que, caso haja uma alteração na classe pai, todas as classes filhas também serão alteradas gerando um efeito dominó.

# Composição / Associação

- COMPOSIÇÃO: os objetos são dependentes de um outro. EX: um objeto A precisa de um objeto B para existir de forma que o objeto A seja criado / instanciado dentro da classe do objeto B.

- ASSOCIAÇÃO: Os objetos independetes podem se comunicar / conectar entre si sem gerar uma dependencia.
